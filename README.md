# Emmet Remove Tag (Context Menu)

## Build
npm install -g vsce
vsce package

## Making changes

* Press `F5` to open a new window with your extension loaded.

### Make changes

- You can also reload (`Ctrl+R`) the VS Code window with your extension to load your changes.

## Publishing

To publish a newer version:
```
vsce publish
```
